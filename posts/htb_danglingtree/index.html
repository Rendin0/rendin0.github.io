    HTB DanglingTree

    Полный разбор машины DanglingTree с HTB
    27 августа 2026 г. | Переводы:
    • En

    Enumeration#

    Энумерация портов показала стандартный контроллер домена Active Directory, на котором запущен веб-сервер.

    $ nmap 10.129.83.210
Nmap scan report for 10.129.83.210
Host is up (0.098s latency).
Not shown: 987 filtered tcp ports (no-response)
PORT     STATE SERVICE
80/tcp   open  http
88/tcp   open  kerberos-sec
135/tcp  open  msrpc
139/tcp  open  netbios-ssn
389/tcp  open  ldap
443/tcp  open  https
445/tcp  open  microsoft-ds
464/tcp  open  kpasswd5
593/tcp  open  http-rpc-epmap
636/tcp  open  ldapssl
3268/tcp open  globalcatLDAP
3269/tcp open  globalcatLDAPssl
3389/tcp open  ms-wbt-server

    Быстро проверив 80 и 443 порты, увидел, что там стоит стандартная заглушка IIS, ничего интересного. Чаще всего веб-сервер на AD контроллере используется для работы с сертификатами, вероятно на машине настроена AD CS. Запустил скан всех портов на машине nmap 10.129.83.210 -p- -T4. Пока nmap работает, решил быстро сделать запись в /etc/hosts и создать krb5.conf файл, для работы с Kerberos в дальнейшем.

    $ sudo nxc smb 10.129.83.210 --generate-hosts /etc/hosts
SMB         10.129.83.210   445    DC               [*] Windows 11 / Server 2025 Build 26100 x64 (name:DC) (domain:danglingtree.htb) (signing:True) (SMBv1:None) (Null Auth:True)

$ sudo nxc smb dc.danglingtree.htb --generate-krb5 /etc/krb5.conf
SMB         10.129.83.210   445    DC               [*] Windows 11 / Server 2025 Build 26100 x64 (name:DC) (domain:danglingtree.htb) (signing:True) (SMBv1:None) (Null Auth:True)
SMB         10.129.83.210   445    DC               [+] krb5 conf saved to: /etc/krb5.conf
SMB         10.129.83.210   445    DC               [+] Run the following command to use the conf file: export KRB5_CONFIG=/etc/krb5.conf

    Введите NT хэш Administrator аккаунта для продолжения чтения
