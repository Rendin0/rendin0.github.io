    HTB Cohort – небольшое приключение

    Разбор машины Cohort с HackTheBox
    28 августа 2026 г. | Переводы:
    • En

    Enumeration#

    Любая машина начинается со скана портов:

    $ nmap 10.129.244.174
Starting Nmap 7.99 ( https://nmap.org ) at 2026-08-28 09:04 +0300

Nmap scan report for 10.129.244.174
Host is up (0.27s latency).
Not shown: 996 closed tcp ports (reset)
PORT    STATE    SERVICE
22/tcp  open     ssh
80/tcp  open     http
443/tcp open     https

    Быстрый скан показал лишь открытые порты для веб-сервиса, а также ssh. Фоном запустил полный скан nmap 10.129.244.174 -p- -T4, а сам в то время пошёл в браузер. Переход по адресу машины перенаправил на домен cohort.htb

    В браузере

    Добавил запись в /etc/hosts. Сразу после решил запустить скан директорий на сайте.

    $ echo "10.129.244.174     cohort.htb" | sudo tee -a /etc/hosts 

$ feroxbuster -u https://cohort.htb --insecure

    Введите хэш root аккаунта для продолжения чтения

    cat /etc/shadow | grep root | awk -F: '{print $2}'
