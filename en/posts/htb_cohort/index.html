    Enumeration#

    Every machine starts with a port scan:

    $ nmap 10.129.244.174
Starting Nmap 7.99 ( https://nmap.org ) at 2026-08-28 09:04 +0300

Nmap scan report for 10.129.244.174
Host is up (0.27s latency).
Not shown: 996 closed tcp ports (reset)
PORT    STATE    SERVICE
22/tcp  open     ssh
80/tcp  open     http
443/tcp open     https

    The quick scan showed only the web service ports and ssh. I kicked off a full scan with nmap 10.129.244.174 -p- -T4 in the background, and in the meantime went to the browser. Visiting the machine’s address redirected me to the domain cohort.htb

    In the browser

    I added an entry to /etc/hosts. Right after that I decided to run a directory scan on the site.

    $ echo "10.129.244.174     cohort.htb" | sudo tee -a /etc/hosts 

$ feroxbuster -u https://cohort.htb --insecure

    Enter the hash of the root account to keep reading

    cat /etc/shadow | grep root | awk -F: '{print $2}'
